# Python Budget Manager

A personal budget management application developed with Python.

Features

- Add income
- Add expenses
- Track current balance
- Calculate total expenses
- View transaction history
- Save financial data between sessions
- Input validation and error handling

Technologies

- Python 3
- File handling (".txt")
- Functions
- Exception handling

How to run

1. Install Python 3.
2. Clone this repository.
3. Run the following command:

python main.py

Learning objectives

This project was developed to practice Python fundamentals, modular programming, file handling and data persistence.
